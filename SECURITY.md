# Security Policy

## Scope

GPT Obsidian Tracker is designed to keep collection on the local machine. The Collector listens only on `127.0.0.1:17321`; cloud summarization is disabled by default.

## Reporting

Please do not open a public issue for credentials, private transcripts, or an exploitable vulnerability. Once the GitHub repository is available, use a private GitHub Security Advisory or contact the repository maintainer privately.

When reporting, include the affected version, operating system, reproduction steps and a minimal redacted example. Never attach `data/`, `logs/`, browser profiles, `.env` files or real Obsidian content.
